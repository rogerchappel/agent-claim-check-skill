# Launch draft feedback fixture

This fixture records reproducible editorial feedback from a real repository launch-draft review.

## Draft under review

> Agent Claim Check Skill provides a local CLI and fixture-backed tests for reviewing generated launch material.
>
> It automatically publishes approved posts to every social network and guarantees that all claims are legally safe.
>
> The checker can emit JSON and markdown reports for orchestration handoffs.

## Feedback

- Keep the first claim only when the README and executable smoke test are the cited evidence.
- Remove the automatic publishing and legal-safety guarantees: neither is supported by the supplied sources, and the tool does not publish content or provide legal review.
- The output-formats claim is supported by the CLI documentation.

## Documented limits applied

Feedback is a human editorial observation, not product proof. This fixture demonstrates a single reviewed draft and does not establish representative user research, validate legal claims, or imply that a launch has been published.
